# 开源了！花了10亿token，这个整支设计团队力量的神级技能来了

## 前言：一个关于"卷"的故事

做UI设计这件事，过去是设计师的专属战场。Sketch、Figma、Adobe全家桶轮番上阵，一个完整的App界面从需求到高保真原型，少说也得折腾两三天。直到某天，有人开始琢磨：能不能让AI把这套活儿也给干了？

于是，这个项目诞生了。经过无数个日夜的调教，累计消耗了超过10亿token的算力，终于把一支完整设计团队的能力，浓缩进了一个Skill里。今天，它正式开源了。

---

## 一、它能干嘛

简单来说，这个Skill的核心能力可以用一句话概括：**一条指令，输出原厂级高保真UI设计方案。**

不是那种粗糙的线框图，也不是看着像那么回事的示意图，而是能直接拿去跟设计师对稿、跟开发对接的完整方案。从设计系统到组件规范，从页面原型到可交互HTML Demo，全流程覆盖。

具体包含以下核心亮点：

| 核心能力 | 说明 |
| :--- | :--- |
| **覆盖11大平台** | Apple iOS、Google Android、Samsung One UI、华为HarmonyOS、小米HyperOS、荣耀MagicOS、OPPO ColorOS、vivo OriginOS、魅族Flyme、Windows 11 Fluent、微信小程序WeUI |
| **原厂级1:1还原** | 严格遵循各平台官方设计规范，像素级对齐，不是"大概像" |
| **一键风格切换** | 同一套需求，秒切不同平台风格，横向对比无压力 |
| **完整组件库** | 按钮、输入框、卡片、导航、弹窗……常用组件一应俱全 |
| **多风格横向对比** | 同屏展示多个平台方案，选型效率翻倍 |
| **零设计基础可用** | 不需要懂Sketch、不需要会Figma，有手就能用 |

---

## 二、为什么是它

市面上的UI生成工具不少，但这个Skill有几个不太一样的地方。

**首先，它真的懂设计规范。**

不是随便拼凑几个圆角和阴影就完事。iOS的Human Interface Guidelines、Android的Material Design 3、各国产厂商的定制规范，这些都被吃透了。生成的界面，拿给对应平台的资深设计师看，大概率挑不出毛病。

**其次，它输出的是完整方案，不是单张图。**

很多工具生成一张界面图就止步了。但这个Skill会给出一整套交付物：设计系统定义、组件使用规范、页面结构说明，甚至还有可交互的HTML Demo。前端同事可以直接拿去参考实现，产品经理也能拿着原型去跟老板汇报。

**再者，跨平台对比这件事，以前想都不敢想。**

做一套App界面，到底选iOS风格还是Material Design？以前得分别找人做两套方案才能对比。现在，一条指令，11种风格并排展示，选型效率直接起飞。

---

## 三、怎么用

使用起来非常简单，核心就三步：

1. **描述需求**：告诉它你要做什么页面，比如"做一个电商商品详情页"
2. **选择平台**：指定设计风格，比如"按iOS风格"或"对比Android和HarmonyOS两种风格"
3. **获取方案**：坐等输出，拿到完整的设计方案和可交互Demo

不需要安装复杂的设计软件，不需要学习专业的设计知识，甚至不需要会画一根线。对于产品经理、独立开发者、初创团队来说，这意味着可以省下一大笔请设计师的费用，同时获得专业水准的产出。

## 四、适合谁

这个Skill的适用人群相当广泛：

- **独立开发者**：没有设计资源，又想做出专业界面的个人开发者
- **初创团队**：预算有限，需要快速产出高保真原型的创业团队
- **产品经理**：需要快速验证想法、制作演示原型的PM
- **前端工程师**：想快速获取设计参考、减少与设计师沟通成本的开发者
- **设计爱好者**：对UI设计感兴趣，想学习不同平台设计规范的学习者

---

## 结尾：设计民主化的又一步

开源这件事，本质上是在降低专业能力的获取门槛。过去，一套专业的UI设计方案需要经验丰富的设计师花费数天甚至数周才能完成。现在，借助这个Skill，任何人都可以在几分钟内获得同等水准的产出。

这并不意味着设计师会被取代。相反，它让设计师可以从重复性的基础工作中解放出来，把精力投入到更有创造性的环节。而对于那些没有设计资源的人来说，这扇原本紧闭的门，终于打开了一条缝。
