## 一、项目速览

**ui-design-aitool-plus** 是一个面向全平台的设计系统生成工具，核心定位就一句话：**一条指令，输出原厂级高保真UI方案**。

不是那种"大概长得像"的模板拼凑，而是真正基于各大厂官方设计规范（Material Design、Apple Human Interface、Ant Design 等）进行 1:1 还原。从配色体系到组件间距，从字体层级到阴影参数，每一处细节都对标原厂。

GitHub 地址：https://github.com/aitool-plus/ui-design-aitool-plus

## 二、核心亮点

### 1. 覆盖11大平台

别的工具还在纠结"支持不支持移动端"，这个项目已经把手伸向了几乎所有主流平台：

| 平台类型 | 代表规范 |
| :--- | :--- |
| Web 端 | Material Design、Ant Design、Element Plus |
| 移动端 iOS | Apple Human Interface Guidelines |
| 移动端 Android | Material You |
| 跨端小程序 | 微信小程序、支付宝小程序、uni-app |
| 桌面端 | macOS、Windows Fluent Design |
| 其他平台 | HarmonyOS、Taro 跨端框架 |

一句话：只要用户能想到的平台，这里基本都有对应的设计方案。

### 2. 原厂级 1:1 还原

很多所谓"设计系统"其实就是网上扒了几个色板、抄了几个按钮样式，拼拼凑凑就上线了。这个项目不一样——它是**基于各大厂官方 Design Token 和组件规范**进行还原的。

什么意思？就是说，生成的按钮不只是"看起来差不多"，而是连 hover 态的过渡时长、阴影的模糊半径、字体的字重和行高，都跟原厂保持高度一致。

### 3. 一键风格切换

今天客户要 Material Design，明天老板要 Apple 风格，后天产品经理又说要 Ant Design……这种反复横跳的痛苦，做设计的都懂。

这个项目支持**一键切换设计风格**。输入一条指令，整个设计系统的配色、圆角、阴影、字体全部自动替换，连组件状态都跟着变。从"谷歌味"切换到"苹果味"，只需要几秒钟。

### 4. 完整组件库

不是只有几个按钮和输入框那种"半成品"。这个项目提供的是**完整的组件库体系**：

- **基础组件**：按钮、输入框、选择器、开关、标签页……
- **布局组件**：栅格系统、卡片、分割线、间距规范……
- **反馈组件**：弹窗、提示、加载、进度条……
- **导航组件**：面包屑、分页、步骤条、侧边栏……

每个组件都附带完整的交互状态（默认、hover、点击、禁用、加载、错误），直接拿来用就行。

### 5. 多风格横向对比

一个特别实用的功能：**同一套界面，可以同时生成多种风格方案进行横向对比**。

比如做后台管理系统，可以一键生成 Material Design 版、Ant Design 版、Element Plus 版，并排摆在一起给老板选。哪个顺眼选哪个，再也不用"先做一个试试"了。

### 6. 零设计基础也能产出专业UI

最狠的是这个——**就算完全不懂设计的人，也能用**。

项目内置了智能设计引擎，用户只需要描述需求（比如"做一个电商商品详情页"），系统就会自动匹配合适的组件、布局和配色，生成可直接交付的高保真UI方案。

设计师看了沉默，产品经理看了流泪。

## 四、快速上手

项目基于 Node.js 开发，安装依赖后一条命令即可启动：

```bash
# 克隆项目
git clone https://github.com/aitool-plus/ui-design-aitool-plus.git

# 安装依赖
cd ui-design-aitool-plus
npm install

# 启动服务
npm run dev
```

启动后，在浏览器中打开对应地址，输入设计需求，即可看到生成的UI方案。

更详细的配置说明和 API 文档，可以参考项目 README。
